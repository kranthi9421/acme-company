# ACME Company

ACME is a React monorepo containing a shared UI library and applications.

## Projects

- shared-ui - Reusable React components and design system
- customer-app - Customer-facing application
- admin-app - Admin application

## Tech Stack

- React
- TypeScript
- Vite
- npm

## Getting Started

Each project has its own dependencies. Navigate to the project folder and run:

npm install
npm run dev


## Repository Structure

- .github/workflows - CI automation
- shared-ui - Shared design system
- customer-app - Customer application
- admin-app - Admin application
